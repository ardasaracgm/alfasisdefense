System Overview

One vehicle.
Full-spectrum counter-UAS.

ALFA SENTINEL is a self-sufficient mobile command and control platform built on a Mercedes-Benz Sprinter 519 chassis. It integrates RF detection, drone jamming, electro-optical tracking, encrypted communications, and operator command infrastructure into a single deployable unit.

Designed for defence, security, and electronic warfare operations — the platform operates independently of external infrastructure, carrying its own power generation, climate control, and mission systems into any field environment.

Core Capabilities
01

RF Detection & Signal Analysis

Full-band scanning from 70MHz to 6GHz. Detects mainstream drones and FPV at ≥5km, identifies drone model, SN, take-off point, return point, and real-time trajectory.

ALFADET System
02

Drone-UAV Jamming

850W total RF output across 430MHz–6GHz. Blocks all GNSS transmitters and control links. Compact roof-mount design: 90×45×152cm, ≤90kg.

ALFA 850V Mobile
03

EO/IR Visual Tracking

4MP optical + thermal bi-spectrum camera with auto slew-to-cue. Pan 360° continuous, tilt ±85°. Day and night operation, fire and smoke detection, laser range up to 2000m.

Thermal + Optical PTZ
04

Encrypted C2 Communications

AES-256 encrypted site-to-site VPN over VSAT/LTE/4G. Secure voice, video conference, radio-over-IP, and public announcement system. EvaGate Core integrated.
