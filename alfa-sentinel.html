System Overview

One vehicle. Full-spectrum counter-UAS.

ALFA SENTINEL is a self-sufficient mobile command and control platform built on a Mercedes-Benz Sprinter 519 chassis. It integrates RF detection, drone jamming, electro-optical tracking, encrypted communications, and operator infrastructure into a single deployable unit.

Operates independently of external infrastructure — carrying its own power generation, climate control, and mission systems into any field environment.

Core Capabilities

Four integrated systems.

01

RF Detection & Signal Analysis

Full-band 70MHz–6GHz scanning. Detects mainstream drones and FPV at ≥5km. Identifies model, SN, take-off point, return point, and real-time trajectory in ≤10 seconds.

ALFADET System
02

Drone-UAV Jamming

850W total RF output across 430MHz–6GHz. Blocks all GNSS transmitters and control links with 360° omnidirectional coverage. Operating range -15°C to +65°C.

ALFA 850V Mobile
03

EO/IR Visual Tracking

4MP optical + thermal bi-spectrum PTZ. Pan 360° continuous, tilt ±85°. 56× optical zoom, laser range up to 2,000m. Fire and smoke detection. Day and night.

Thermal + Optical PTZ
04

Encrypted C2 Communications

AES-256 site-to-site VPN over VSAT/LTE/4G. Secure voice, video conference, radio-over-IP, public announcement. EvaGate Core with redundant multi-link connectivity.
